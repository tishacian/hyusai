## Limites avant activation

Les tests d’interface utilisent des réponses API simulées : ils valident le
parcours, pas les lectures PostgreSQL ou l’exécution du nouveau backend en live.
Après déploiement par l’opérateur, vérifier le SHA servi, charger les fixtures,
produire le mapping des vrais Source IDs et activer la release. Conserver les
liens vers les trois vrais Runs et refaire le parcours documentaire.

Le benchmark humain n’a pas été exécuté. Aucun temps, coût complet, gain net ou
ROI n’est annoncé. Utiliser le [runbook opérateur](OPERATOR-RUNBOOK.md) et le
[protocole de mesure](ROI-PROTOCOL.md) pour réaliser et examiner ces observations.
