

## Core Product Vision (Agentium)
[2026-02-10] - Agentium is not an agent builder, but a system to design, run and pilot intelligence that produces measurable value.
[2026-02-10] - Core loop: Execute → Outcome → Decision → Control → Allocate.
[2026-02-10] - Primary objective: make AI systems observable, controllable, and economically measurable.

## Core Objects (Canonical Model)
[2026-02-10] - Portfolio: aggregation of capabilities and systems at organization level.
[2026-02-10] - Capability: business-level function producing measurable value (e.g. contract risk detection).
[2026-02-10] - System: orchestrated set of skills producing outcomes.
[2026-02-10] - Run: execution instance of a system.
[2026-02-10] - Skill: atomic unit (OCR, LLM, classifier, API call, etc.).
[2026-02-10] - Outcome: {cost, value, confidence, efficiency} — mandatory output of every run.
[2026-02-10] - Decision: action taken based on outcomes.
[2026-02-10] - Decision Unit: Decision + Outcome + Context (aggregation unit).

## Core Architecture Layers
[2026-02-10] - Execution Layer: systems, runs, skills.
[2026-02-10] - Outcome Layer: value, cost, confidence, efficiency.
[2026-02-10] - Decision Layer: decisions derived from outcomes.
[2026-02-10] - Control Plane: resource, velocity, autonomy, risk_tolerance.
[2026-02-10] - Hypervisor: strategic cockpit aggregating outcomes, decisions and control.

## Navigation Model (UX Structure)
[2026-02-10] - Hierarchy (breadcrumb): Portfolio → Capability → System → Run → Skill.
[2026-02-10] - Function (verbs): Hypervisor, Build, Operate, Steer, Govern.
[2026-02-10] - Mini-rail: scope selector (object type), NOT navigation.
[2026-02-10] - Tabs: representation of the same object, NOT navigation.
[2026-02-10] - Command palette (⌘K): direct access without breaking context.

## UX Principles (Agentium)
[2026-02-10] - Continuous canvas: no page switching, only perspective shifts.
[2026-02-10] - Outcome-first UI: value must be visible everywhere.
[2026-02-10] - Real-time system: every interaction produces immediate feedback.
[2026-02-10] - Control as interaction: no hidden settings.
[2026-02-10] - Semantic zoom: same object, different abstraction levels.

## Differentiation Thesis
[2026-02-10] - Agentium competes on system-level coherence, not feature completeness.
[2026-02-10] - Metrics are product (ROI, cost, efficiency), not logs.
[2026-02-10] - UI is a control system, not a dashboard.
[2026-02-10] - Value visibility is the primary UX driver.
