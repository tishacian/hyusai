# Contrat de service - transporteur fictif ColisAzur

DÉMONSTRATION SYNTHÉTIQUE - aucun client ni remboursement réel

Version : 1 | Date : 2026-09-01 | En vigueur / pièce courante

ColisAzur est un transporteur fictif du jeu de démonstration Luma Maison. Aucune livraison commerciale réelle n'est représentée par ce contrat.

Clause 1 - Une preuve de livraison doit identifier la commande, le numero de suivi, la date et le code postal du lieu de remise.

Clause 2 - En cas de divergence entre le code postal de commande et celui du bordereau, fournir une confirmation du lieu de remise. Le statut livré seul ne clôt pas l'enquête.

Clause 3 - Le SAV peut demander une enquête avec la référence de commande et la pièce contradictoire. La réponse de démonstration doit identifier clairement les informations confirmées et celles encore inconnues.

Clause 4 - Une confirmation de perte doit porter le numero de suivi, la commande et la date de confirmation. Elle autorise l'examen d'une solution commerciale, pas une exécution financière automatique.
