# Dossier — Rumeur frontiere Nord (25 mai 2026)

**Date** : 25 mai 2026, midi-debut d'apres-midi
**Auteur** : Cellule veille SENTINEL-CI
**Objet** : Reconstitution OSINT de la chaine de diffusion d'une rumeur d'incursion frontaliere Nord et capture du démenti officiel.
**Sensibilite** : tous les comptes cites sont publics ou pseudonymises pour la demo.

---

## 1. Synthese executive

Un signal OSINT initial — tweet d'un compte citoyen pseudonyme — a fait monter dans la matinée du 25 mai 2026 une rumeur d'incursion frontaliere dans la zone Bouna / Kong. La chaine de diffusion suit le pattern typique : tweet origine, relai Telegram regional, article blog non source, amplification anonyme, puis démenti officiel par la FANCI et la Préfecture Nord.

Aucun element terrain n'a confirme la rumeur. Les postes mixtes sont nominaux. Le démenti officiel a été publié a 13h46.

## 3. Analyse pattern

- **Origine** : compte citoyen pseudonyme, peu de followers, géoloc indicative Bouna.
- **Vecteur d'amplification** : Telegram joue le role de catalyseur regional, suivi d'un blog secondaire qui legitime apparemment l'information sans citer de source primaire.
- **Indicateurs faibles** : pas de photo / video / temoignage primaire dans la chaine. Pas de relai par un compte officiel ou un media reconnu.
- **Vitesse de retour officiel** : démenti FANCI a +2h04 sur le tweet origine, démenti Préfecture Nord a +2h10. Cible cabinet : démenti officiel sous 90 minutes — depasse de 34 minutes, a optimiser.

## 4. Sources et démentis

- **Sources rumeur** : 4 comptes pseudonymes (X, Telegram), 1 blog regional pseudonyme.
- **Sources démenti** : `@FANCIofficiel` (officiel, vérifié), `@PrefectureNord` (officiel, vérifié), confirmation cellule terrain via canal interne SENTINEL-CI.
- **Cellule terrain** : aucun incident remonte sur les postes mixtes Bouna / Kong / Téhini entre 06h00 et 14h00.

## 5. Recommandation pour le VP

1. **Communique court souverain** : rappeler que la rumeur est démentie officiellement, citer les sources FANCI et Préfecture.
2. **Communication preventive** : preparer un message de réassurance pour les communautes locales du Nord, sans mentionner les comptes pseudonymes ni amplifier la rumeur initiale.
3. **Suivi internal** : raccourcir la cible cabinet de réponse officielle a 60 minutes (vs 90 actuellement) pour les rumeurs frontiere.
4. **Lecture pour le Conseil 15h00** : presenter ce dossier comme support du point « Communication souveraine sur signaux faibles ».
