# Dossier — Rumeur frontière Nord (25 mai 2026)

**Date** : 25 mai 2026, midi-début d'après-midi
**Auteur** : Cellule veille SENTINEL-CI
**Objet** : Reconstitution OSINT de la chaîne de diffusion d'une rumeur d'incursion frontalière Nord et capture du démenti officiel.
**Sensibilité** : tous les comptes cités sont publics ou pseudonymisés pour la démo.

## 1. Synthèse exécutive

Un signal OSINT initial — tweet d'un compte citoyen pseudonyme — a fait monter dans la matinée du 25 mai 2026 une rumeur d'incursion frontalière dans la zone Bouna / Kong. La chaîne de diffusion suit le pattern typique : tweet origine, relais Telegram régional, article de blog non sourcé, amplification anonyme, puis démenti officiel par la FANCI et la Préfecture Nord.

Aucun élément terrain n'a confirmé la rumeur. Les postes mixtes sont nominaux. Le démenti officiel a été publié à 13h46.

## 3. Analyse pattern

- **Origine** : compte citoyen pseudonyme, peu de followers, géoloc indicative Bouna.
- **Vecteur d'amplification** : Telegram joue le rôle de catalyseur régional, suivi d'un blog secondaire qui légitime apparemment l'information sans citer de source primaire.
- **Indicateurs faibles** : pas de photo, vidéo ou témoignage primaire dans la chaîne. Pas de relais par un compte officiel ou un média reconnu.
- **Vitesse de retour officiel** : démenti FANCI à +2h04 sur le tweet origine, démenti Préfecture Nord à +2h10. Cible cabinet : démenti officiel sous 90 minutes — dépassement de 34 minutes, à optimiser.

## 4. Sources et démentis

- **Sources rumeur** : 4 comptes pseudonymes (X, Telegram), 1 blog régional pseudonyme.
- **Sources démenti** : `@FANCIofficiel` (officiel, vérifié), `@PrefectureNord` (officiel, vérifié), confirmation cellule terrain via canal interne SENTINEL-CI.
- **Cellule terrain** : aucun incident remonte sur les postes mixtes Bouna / Kong / Téhini entre 06h00 et 14h00.

## 5. Recommandation pour le VP

1. **Communiqué court souverain** : rappeler que la rumeur est démentie officiellement, citer les sources FANCI et Préfecture.
2. **Communication préventive** : préparer un message de réassurance pour les communautés locales du Nord, sans mentionner les comptes pseudonymes ni amplifier la rumeur initiale.
3. **Suivi interne** : raccourcir la cible cabinet de réponse officielle à 60 minutes (vs 90 actuellement) pour les rumeurs frontière.
4. **Lecture pour le Conseil 15h00** : présenter ce dossier comme support du point « Communication souveraine sur signaux faibles ».
