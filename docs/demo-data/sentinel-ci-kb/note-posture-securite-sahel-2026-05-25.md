# Note de posture sécurité — théâtre Sahel

**Date** : 25 mai 2026, 10h00 (Abidjan)
**Auteur** : Conseiller sécurité, Cabinet du Vice Premier Ministre
**Distribution** : Vice Premier Ministre, Directeur de cabinet, Cellule veille SENTINEL-CI

## 1. Synthèse exécutive

Le théâtre Sahel reste sous surveillance élevée mais sans escalade nouvelle au cours des dernières 72 heures. Trois zones concentrent l'attention :

- **Liptako-Gourma** (tripoint Mali / Burkina / Niger) : activité cinétique faible mais constante, flux de population sous tension.
- **Frontière Mali / Burkina** (axe Tominian-Yoro) : signaux faibles relayés par RSS locaux, aucune intervention ouverte confirmée.
- **Région de Tillabéri (Niger)** : pression humanitaire confirmée par les agences ONU, ACLED note une stabilité opérationnelle relative.

La Côte d'Ivoire reste à distance immédiate des théâtres, mais la coordination CEDEAO active deux hubs logistiques clés : la base CEDEAO d'Abidjan (plateforme logistique régionale) et le hub de coordination corridor Korhogo-Bamako, en posture stable.

## 3. Lecture OSINT publique (synthèse)

Les sources publiques (ACLED, RFI Sahel, Jeune Afrique, presse locale) convergent sur trois constats stables depuis 7 jours :

1. **Continuité opérationnelle CEDEAO** : la coordination régionale fonctionne, les flux logistiques sont nominaux.
2. **Pression humanitaire** : la zone Tillabéri-Liptako concentre les besoins ; aucune crise nouvelle déclenchée.
3. **Activité informationnelle** : faible volume de propagande externe ciblant la Côte d'Ivoire ; les comptes habituels restent silencieux sur le sujet Sahel.

## 4. Implications Côte d'Ivoire

- **Frontière Nord** : aucun signal terrain n'a remonté d'incident pendant la nuit. Les postes mixtes sont nominaux. Le seul signal du jour est une rumeur OSINT démentie (voir dossier `dossier-rumeur-frontiere-nord-2026-05-25.md`).
- **Base CEDEAO Abidjan** : posture stable, rôle de plateforme logistique confirmé.
- **Hub corridor Mali** : posture watch — coordination Korhogo-Bamako sur les flux logistiques.

## 5. Recommandation pour le Conseil Défense 15h00

Au Conseil Défense restreint de 15h00, il est proposé :

1. **Valider la posture dual-axis** : intérieur vigilance, extérieur élevé.
2. **Confirmer la communication du démenti officiel** sur la rumeur frontière Nord.
3. **Présenter la lecture OSINT publique** comme support neutre.
4. **Demander un point de coordination CEDEAO** sur le corridor Korhogo-Bamako d'ici fin de semaine.

Aucune action militaire ou cinétique n'est recommandée : le théâtre reste sous surveillance, pas en posture d'intervention.
