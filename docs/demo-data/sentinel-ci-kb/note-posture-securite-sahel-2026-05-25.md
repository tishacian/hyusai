## 1. Synthese executive

Le theatre Sahel reste sous surveillance elevee mais sans escalade nouvelle au cours des dernieres 72 heures. Trois zones concentrent l'attention :

- **Liptako-Gourma** (tripoint Mali / Burkina / Niger) : activite cinetique faible mais constante, flux de population sous tension.
- **Frontiere Mali / Burkina** (axe Tominian-Yoro) : signaux faibles relayes par RSS locaux, aucune intervention ouverte confirmee.
- **Region de Tillaberi (Niger)** : pression humanitaire confirmee par les agences ONU, ACLED note une stabilite operationnelle relative.

La Cote d'Ivoire reste a distance immediate des theatres, mais la coordination CEDEAO active deux hubs logistiques cles : la base CEDEAO d'Abidjan (plateforme logistique regionale) et le hub de coordination corridor Korhogo-Bamako, en posture stable.

## 3. Lecture OSINT publique (synthese)

Les sources publiques (ACLED, RFI Sahel, Jeune Afrique, presse locale) convergent sur trois constats stables depuis 7 jours :

1. **Continuite operationnelle CEDEAO** : la coordination regionale fonctionne, les flux logistiques sont nominaux.
2. **Pression humanitaire** : la zone Tillaberi-Liptako concentre les besoins ; aucune crise nouvelle declenchee.
3. **Activite informationnelle** : faible volume de propagande externe ciblant la Cote d'Ivoire ; les comptes habituels restent silencieux sur le sujet Sahel.

## 4. Implications Cote d'Ivoire

- **Frontiere Nord** : aucun signal terrain n'a remonte d'incident pendant la nuit. Les postes mixtes sont nominaux. Le seul signal du jour est une rumeur OSINT démentie (voir dossier `dossier-rumeur-frontiere-nord-2026-05-25.md`).
- **Base CEDEAO Abidjan** : posture stable, role de plateforme logistique confirmé.
- **Hub corridor Mali** : posture watch — coordination Korhogo-Bamako sur les flux logistiques.

## 5. Recommandation pour le Conseil Defense 15h00

Au Conseil Defense restreint de 15h00, il est propose :

1. **Valider la posture dual-axis** : interieur vigilance, exterieur elevee.
2. **Confirmer la communication du démenti officiel** sur la rumeur frontiere Nord.
3. **Présenter la lecture OSINT publique** comme support neutre.
4. **Demander un point de coordination CEDEAO** sur le corridor Korhogo-Bamako d'ici fin de semaine.

Aucune action militaire ou cinetique n'est recommandee : le theatre reste sous surveillance, pas en posture d'intervention.
