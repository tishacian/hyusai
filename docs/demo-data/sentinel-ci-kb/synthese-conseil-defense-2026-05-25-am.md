## 2. Decisions et orientations

- **Posture interieure** : maintenir le niveau VIGILANCE. Le Cabinet confirme la coordination cellule terrain — Préfecture Nord pour traiter tout signal frontiere en moins de 90 minutes.
- **Posture exterieure Sahel** : maintenir le niveau ELEVEE. Pas de modification operationnelle, surveillance ADS-B advisory continue.
- **CEDEAO** : un point de coordination sera demande d'ici fin de semaine sur le corridor logistique.
- **Communication** : Cabinet communique systematiquement les démentis officiels sur les rumeurs Nord dans les 90 minutes apres signalement.
- **Defense budget** : reponse cabinet preparee pour 14h sur l'article L'Inter — pas de polemique, factuelle, sourcee.

## 3. Items pour la revue 15h00

La revue operations Sahel de 15h00 reprendra trois items :

1. **Lecture OSINT publique** consolidee (note `note-posture-securite-sahel-2026-05-25.md`)

## 4. Cadre advisory-only

Le Conseil rappelle que toute communication advisory ou operationnelle reste sous validation humaine. Les outils SENTINEL-CI / AYA fournissent un support de lecture, pas d'actionneur. Le score réputation hebdomadaire (72/100, +4 pts) est utilise comme indicateur de tendance, pas comme metrique decisionnelle.

## 5. Risques residuels

- Risque de réamplification d'une rumeur si le démenti officiel n'est pas relaye sur les canaux institutionnels en moins de 30 minutes.
- Risque de confusion entre signal frontiere et flux logistique CEDEAO — bien distinguer les deux dans la communication publique.
- Risque de surinterpretation de l'activite ADS-B advisory : disclaimer systematique dans tout brief externe.
