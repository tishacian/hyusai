# Software Requests and Licences

## 1. The approved catalogue

Software available without a business case is listed in the approved catalogue in
the self-service portal. Catalogue items are pre-licensed, pre-tested against the
standard build, and installed without a manager approval where the licence is
already held.

Anything outside the catalogue requires a business case approved by the line
manager and, above a value threshold, by the budget holder.

## 2. Installing catalogue software

Catalogue items install from the self-service portal on corporate laptops without
administrator rights. The target is installation within 1 working day of the
request, and most items install immediately.

Installation on a plant workstation is scheduled with the site, because those
machines are only updated inside a maintenance window.

## 3. Non-catalogue requests

A non-catalogue request must state what the software does, why a catalogue item
cannot do it, the number of users, and the expected duration of use. IT Asset
Management checks the licence terms, the security review status, and the
compatibility with the standard build.

The target for a decision is 5 working days. A request that requires a new
supplier or a data protection review takes longer, and the requester is told so
at the outset.

Free and open-source software is not exempt from this process: licence terms and
the security review apply regardless of price.

## 4. Administrator rights

Local administrator rights are not granted to install software. Where a role
genuinely requires them, they are granted as a separate, named, time-limited
entitlement approved by the IT Security Office, and never as a permanent
attribute of the user's own account.

## 5. Licence reclaim

Licences are reclaimed when they are unused for 60 consecutive days, and when a
user leaves or changes role. The user and the line manager are notified 7 days
before a reclaim, and may keep the licence by stating the continuing need.

Reclaim exists because unused licences are the largest avoidable line in the
software budget; the monthly report to the IT management team lists reclaimed and
retained licences by team.

## 6. Personal software and cloud services

Personally licensed software must not be installed on corporate devices, and
corporate data must not be placed in a cloud service that has not been through
the security review. Staff who need a service that does not exist internally
should ask rather than improvise: a request that is refused is far cheaper than
data in an unapproved service.

## 7. Renewals

Annual renewals are consolidated in the first quarter. Owners of non-catalogue
software confirm the continuing need at that point; software nobody confirms is
not renewed.
